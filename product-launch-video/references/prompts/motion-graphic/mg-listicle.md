# Point Listicle

## When to use
Three to five points, each earning its own scene. Use only when each point is
genuinely distinct — otherwise it is one idea and should be one scene.

## Beat structure
| Beat | Time | On screen | Motion | SFX |
|---|---|---|---|---|
| 1 | 0:00–0:03 | Title card — what this list is | `kinetic-headline` | `whoosh` |
| 2..n | 3–4s each | One point per scene: `numbered-badge` + one line + one visual | `v-click` in, `zoom` on the key word | `pop` |
| last | 0:52–0:60 | The point that ties them together, then ending | `highlight-box` | `success` |

## Copy skeleton
`{N} things about {topic}.` / `{Point 1 — stated as an outcome, not a feature.}` / … / `{What ties them together.}` / `{CTA.}`

## Objects used
`numbered-badge` `kinetic-headline` `highlight-box` `stat-tile` `page-turn`

## Variants
- Exactly three points: consider `before-after` instead — a list of three rarely
  needs a list.
- If points have a clear order, use the `timeline` object rather than badges.
