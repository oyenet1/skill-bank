# Chronological Montage

## When to use
The images are in a real order and the order is the story.

## Beat structure
| Beat | Time | On screen | Motion | SFX |
|---|---|---|---|---|
| 1 | 0:00–0:05 | Start point, dated | `fade-in` | `ambient` |
| 2..n | 6–8s each | Image + date + one line | `slide` along `timeline` | `click` |
| last | final 6s | Where it lands now + ending | `zoom` | `success` |

## Copy skeleton
`{Start.}` / `{Date + one line per image.}` / `{Where it is now.}` / `{CTA.}`

## Objects used
`timeline` `slide` `lower-third`

## Variants
- Do not reorder images to improve the story. If the real order is weak, change
  the framing, not the facts.
