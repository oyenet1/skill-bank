# Before / After

## When to use
The argument is a difference. Show both states honestly, side by side.

## Beat structure
| Beat | Time | On screen | Motion | SFX |
|---|---|---|---|---|
| 1 | 0:00–0:08 | "Before" state, named plainly | `fade-in` | `ambient` |
| 2 | 0:08–0:16 | The cost of that state | `dim-others`, `alert` marker | `alert` |
| 3 | 0:16–0:32 | "After" state, same framing | `split-screen` → `wipe` to full | `whoosh` |
| 4 | 0:32–0:40 | What actually changed — one line | `highlight-box` | `success` |
| 5 | 0:40–0:45 | Ending per §4 | settle | `success` |

## Copy skeleton
`{Before — describe it as the audience would.}` / `{What that costs.}` / `{After.}` / `{The one thing that changed.}` / `{CTA.}`

## Objects used
`split-screen` `wipe` `comparison-table` `highlight-box` `callout-box`

## Variants
- Never fabricate the "before". If you only have one state, use `mg-problem-reveal`.
