# Project Ladder

Use this reference to propose chapter and section projects in the course map or develop one teacher-selected project.

## Placement

- Every chapter ends with a small, tangible project based on that chapter and its prerequisites. A first computer-basics project may be labeling parts or organizing files rather than writing code.
- Every section ends with a larger project integrating its chapters. Schedule at least three chapter projects before the first section project. Later section projects may combine more concepts and require more independent decisions.
- List proposed project titles and the concept IDs they use in the map. The teacher selects a project to develop one at a time. Do not write every project brief or AI prompt pack during course planning.

## Develop one project

Give the selected project a real learner-facing goal, audience or user, expected artifact, bounded feature or task list, prerequisite concept map, build stages, validation, and a completion rubric. Each stage follows **needed concept → simple explanation → example → demonstrated step → learner build step**. If a concept is new, insert it into the course map before the project step that uses it and update affected dependencies.

Increase difficulty by reducing scaffolding and combining ideas, not by adding unrelated technologies. For programming, move from small local tasks to guided applications, integrated systems, then independent work as the learner becomes ready. Realtime features, a particular ORM, or a fixed project count apply only when the teacher's goal calls for them. Feature-by-feature AI prompts are a separate requested asset.

## Optional project prompt pack

When the teacher asks for build prompts, write one project overview prompt and then one prompt per feature or build stage in dependency order. Each prompt names the project goal, target feature, selected stack and known versions when relevant, prerequisites, input files or data, expected output, constraints, and a concrete way to check completion. Include an integration prompt only when separately built features need joining. Keep learner-facing prompts separate from teacher solutions. Do not impose an AI tool or technology stack the teacher did not choose.

When revising a project, preserve its ID and update its concept map, related chapter or section overview, table of contents, assignments, and media references that use the changed project.
