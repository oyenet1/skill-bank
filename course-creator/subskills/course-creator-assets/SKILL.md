# Course Assets

Read the [bundled asset guide](../../references/bundled-assets.md) and the visual-sourcing section of the [media workflow](../../references/visual-media.md). Inspect teacher-supplied files and the 580 bundled SVGs first; choose visuals that explain the exact concept rather than decorate it. If none fits, use a reusable web image with recorded terms, an image-generation tool, or an editable SVG or diagram as appropriate.

Copy selected media into the course `assets/` folder so notes, Slidev, PDF, and video can use the same portable file. Record source, original bundled path or URL, known use terms or pending verification, concept IDs, alt text, and caption in `assets/manifest.json`. Inspect the result at its intended size. Never treat an icon alone as proof of a process or use a product logo to imply endorsement.
