# Device object assets

56 manually reviewed images imported unchanged from devmock. No visible
stock watermark or provider credit was found in the included images. The manifest
records provenance, hashes, dimensions, excluded sources and duplicate variants.

These are raster device illustrations and mockups, not 3D models or proof of
product behavior. Some contain built-in screen placeholders or baked-in
checkerboards/backgrounds. Inspect the selected image before composing it; do
not assume every PNG is transparent. Keep selected copies in the output project.
Reuse rights are not established by the watermark check; do not label these as
public-domain or automatically covered by this repository's MIT code license.
