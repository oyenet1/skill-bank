# Course Slides

Read the Slidev section of the [media workflow](../../references/visual-media.md) and the [bundled asset guide](../../references/bundled-assets.md). Use the teacher's lesson, concept brief, or course map. Reveal a relatable example, What/Why/Where/When/How, visual cause and effect, demonstration, and learner check in understandable steps. Give each storyboard beat a stable concept and beat ID.

Inspect and copy relevant course or bundled images and icons into the course before using them. If an illustration needs sourcing or creation, also read the [assets subskill](../course-creator-assets/SKILL.md). Keep a readable final state so an exported PDF remains useful. Confirm current Slidev syntax and export options with documentation. Produce a PDF only when requested, inspect it, and register the deck, storyboard, and PDF as separate artifacts with actual dependencies. A deck can stand alone and does not trigger video production.
