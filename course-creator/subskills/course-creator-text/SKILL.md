# Course Text

Read [teaching content](../../references/teaching-content.md) and the requested asset's guide: [written production](../../references/text-course-production.md), [teaching assets](../../references/teaching-assets.md), or [projects](../../references/projects.md). For programming topics also read the [technical profile](../../references/technical-profile.md). Work from the mapped outcome and actual learner level, or a standalone teacher brief if no course map exists.

Teach each selected concept through a relatable example or supplied story, What/Why/Where/When/How, a visual explanation, practical demonstration, and learner check. Exercises are optional. Use a relevant still image or icon from the [bundled asset guide](../../references/bundled-assets.md) when it helps; for sourcing or creating a missing visual, also read the [assets subskill](../course-creator-assets/SKILL.md). Copy selected media into the course before linking it. Produce only the requested written assets, keep teacher answers separate, and register actual paths and dependencies in the map.
